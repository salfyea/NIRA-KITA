# Jejak Nira (NIRA KITA)

Prototipe konsep ekosistem pembelajaran dan pelestarian pengetahuan gula kelapa Cilongok.
Saat ini tersedia pengalaman **Pelajar** (5 tab: Beranda, Belajar, Jelajahi, Lab, Paspor) plus Peta simulasi.

## Jalankan
    npm install
    npm run dev      # http://localhost:5173
    npm run build

## Deploy ke Vercel
Preset Vite. `vercel.json` sudah berisi rewrite agar rute `/learn/*` bekerja.
