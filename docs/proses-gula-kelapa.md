# Spesifikasi proses gula kelapa cetak (untuk game "Dapur Gula")

Status: **draf, menunggu validasi kurator dan perajin.** Disusun dari pencarian sumber terbuka. Angka berbeda antar sumber; game memakai
rentang yang paling sering muncul dan menandainya "menunggu validasi komunitas". Jangan menyajikannya sebagai standar teknis.

## Urutan dan klaim yang dipakai
| Langkah | Klaim di game | Dasar |
| --- | --- | --- |
| Penyadapan dan wadah | Nira ditampung di pongkor bambu yang diberi laru alami (kapur dan cangkang manggis) agar tidak cepat asam; nira tidak boleh dibiarkan lama sebelum dimasak. | Liputan Detik 2013 (Banyumas); jurnal pengawet alami nira. Takaran laru **tidak** disebut (belum ada sumber). |
| Penyaringan | Disaring dengan kain bersih untuk membuang bunga kelapa, lebah, semut; langsung ke wajan. | Jurnal pengabdian Banyumas (Polbangtan/UNSOED). |
| Pemasakan | Api besar di awal; buih dan kotoran halus dibuang; 25-30 liter butuh sekitar 4-5 jam; akhir pemasakan sekitar 105-110 C (sumber lain: 110-120 C); warna makin cokelat, buih berkurang. | Jurnal Pembangunan Pedesaan 2012; Liputan6 (Cilongok, ±5 jam); skripsi/tesis lain. |
| Pengadukan | Pengadukan manual yang tidak konsisten disebut sebagai masalah mutu. | Bab tesis (Poltekkes Yogyakarta). |
| Pencetakan | Dituang saat suhu pekatan turun sekitar 70 C; cetakan umumnya setengah tempurung kelapa (bathok). | Jurnal Polbangtan; sumber cetakan bathok pada literatur gula kelapa cetak. |
| Alat | Jubung (anyaman bambu) dipakai sebagian perajin untuk mengurangi buih. | Penelitian "penerapan jubung" (Neliti). |

## Yang belum terverifikasi (butuh narasumber)
- Nama lokal alat di Cilongok (mis. wajan tembaga disebut "jadi" di satu liputan; pengaduk belum ada nama).
- Takaran laru, durasi pasti sejak sadap sampai masak (sebuah liputan menyebut penderes menargetkan kurang dari 2 jam).
- Apakah perajin Cilongok memakai jubung, dan suhu akhir yang mereka pakai (biasanya dibaca dari tanda, bukan termometer).
- Standar mutu terbaru (SNI) gula kelapa cetak; kadar air tidak dipakai di game karena belum diverifikasi.
